## 2-1 必要なツールの全体像

診断を始める前に、最低限以下のツールを用意する。

| ツール | 用途 |
|---|---|
| OS（Windows 11） | 診断作業の基盤 |
| Burp Suite | リクエスト・レスポンスの確認・操作 |
| Chrome / Firefox | 診断対象アプリの操作 |
| プロキシ拡張機能 | ブラウザとBurp Suiteを連携させる |

この章では各ツールのインストールと設定手順を説明する。

---

## 2-2 Burp Suite

Burp SuiteはWebアプリ診断で最も広く使われるプロキシツールだ。ブラウザとサーバーの通信の間に割り込み、リクエストとレスポンスをリアルタイムで確認・改ざんできる。

### エディションの選び方

Burp Suiteには主に2つのエディションがある。

| エディション | 費用 | 向いている用途 |
|---|---|---|
| **Community Edition** | 無料 | 学習・個人練習 |
| **Professional Edition** | 有料（年間ライセンス） | 実務・企業での診断 |

学習目的であればCommunity Editionで十分だ。本書の内容もCommunity Editionで実践できる。

実務では企業がProfessional Editionのライセンスを購入して診断員に提供するのが一般的だ。スキャン機能や自動化機能など、診断効率を上げる機能がProfessional Editionには備わっている。

### インストール

公式サイト（portswigger.net）からインストーラーをダウンロードして実行する。インストール自体は手順に従うだけで完了する。

### CA証明書のインストール

プロキシ設定が完了しただけでは、HTTPSのサイトを診断しようとするとブラウザが警告を出して通信を遮断してしまう。これはBurp SuiteがHTTPS通信を復号するために独自の証明書を使っているためだ。

これを解決するには、Burp SuiteのCA証明書をブラウザに信頼させる必要がある。手順は以下の通りだ。

1. Burp Suiteを起動した状態でブラウザを開き、`http://burpsuite` にアクセスする
2. 「CA Certificate」をクリックして証明書ファイル（`cacert.der`）をダウンロードする
3. ブラウザの証明書管理画面を開き、ダウンロードした証明書をインポートする
   - Chrome：「設定」→「プライバシーとセキュリティ」→「セキュリティ」→「証明書の管理」
   - Firefox：「設定」→「プライバシーとセキュリティ」→「証明書を表示」→「認証局」タブ→「読み込む」
4. 「このCAによるWebサイトの識別を信頼する」にチェックを入れてインポートする

この設定が完了すれば、HTTPSサイトの通信もBurp Suiteで確認できるようになる。**初心者が最初につまずきやすいポイントのひとつ**なので、動作確認は必ず行っておこう。

## 2-3 ブラウザの準備

診断にはChromeとFirefoxの両方を用意することを勧める。

理由は、**ブラウザによって脆弱性の現れ方が異なる場合があるからだ**。同じアプリを診断していても、ChromeとFirefoxで挙動が違うことは実務でもよく起きる。片方だけで診断していると見落としにつながる可能性がある。

### 診断専用ブラウザを用意する

普段使いのブラウザをそのまま診断に使うのは避けた方がよい。理由は2つある。

ひとつは**セキュリティ上のリスク**だ。診断中はBurp Suiteを通じてさまざまなリクエストを送信するが、普段使いのブラウザには個人の認証情報やセッションが保存されている。誤操作で個人アカウントに影響が出るリスクがある。

もうひとつは**設定の煩雑さ**だ。プロキシをONにした状態で普段のWebブラウジングをしようとすると、Burp Suiteが邪魔をして通常のサイトも閲覧しにくくなる。

対策として、Chromeであれば別のプロファイルを作成し、そのプロファイルを診断専用として使う方法が手軽だ。Firefoxも同様にプロファイルを分けることができる。こうすることで診断環境と日常環境をはっきり分離できる。

プロファイルを分けるべき理由がもうひとつある。**エビデンス（証跡）のスクリーンショット撮影**だ。

診断では脆弱性を発見した際に、その画面をスクリーンショットで記録し報告書に添付する。このときブラウザに個人用プロファイルのままで作業していると、アイコンやお気に入りのバーなど個人の情報が画面に映り込んでしまう。報告書はクライアントに納品する公式文書であるため、こうした個人情報が含まれるのは望ましくない。

診断専用プロファイルはアイコンを設定せず、お気に入りバーも非表示にしておくのが望ましい。細かい点に思えるが、報告書の品質と情報管理の両面で重要な習慣だ。

## 2-4 プロキシの設定

Burp Suiteを使った診断の基本的な通信の流れはこうだ。

```
ブラウザ → Burp Suite（プロキシ）→ 診断対象サーバー
```

ブラウザの通信をBurp Suiteに通すことで、送受信されるすべてのHTTPリクエスト・レスポンスを確認できるようになる。

### Windowsのシステムプロキシ設定

Windowsの設定からプロキシを設定する方法が基本だ。

1. 「設定」→「ネットワークとインターネット」→「プロキシ」を開く
2. 「手動プロキシ セットアップ」をオンにする
3. アドレスに `127.0.0.1`、ポートに `8080` を入力する（Burp Suiteのデフォルト）
4. Burp Suiteを起動して通信が通ることを確認する

### ブラウザ拡張機能でプロキシを切り替える

Windowsのシステムプロキシを変更すると、すべてのアプリの通信に影響が出る。診断中と通常作業中でプロキシを素早く切り替えたい場合は、ブラウザ拡張機能を使うと便利だ。

代表的なものにFoxyProxyやSwitchyOmegaがある。これらはプロファイルを登録しておきワンクリックでプロキシのON/OFFを切り替えられるため、診断中と通常作業の切り替えに便利だ。ChromeとFirefoxどちらにも対応したものが多く公開されているので、使いやすいものを選ぶとよい。

## 2-5 ツール使用前の確認事項

ここで重要な注意点を挙げておく。

**企業の環境でBurp Suiteや拡張機能を使う場合は、事前に情報システム部門等に確認が必要な場合がある。**

企業によっては使用可能なツールが社内規定で定められており、無断でインストールや設定変更を行うと規定違反になるケースがある。実務で診断を行う際は、使用ツールについて事前に確認しておくことを強く勧める。

個人の学習環境であれば特に制限はないが、企業・組織の端末を使う場合はこの点を忘れずに。
